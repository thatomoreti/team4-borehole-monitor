    Firestore Schema & Actions

    Structure stored in Firestore:

    boreholes (collection)
 └─ {boreholeId} (doc)
     name, location, is_active, created_at, last_entry_at
     entries (subcollection)
       └─ {entryId} (doc)
           water_level, pump_status, electricity_usage, notes, source, created_at, blockchain
     predictions (subcollection under entry)
           risk_score, remark, created_at

    What I integrated

    • Firestore connection and real-time listeners
    • Save boreholes, entries, predictions (simulated AI)
    • Charts auto-updated from Firestore
    • Blockchain verification simulated and tx-hash stored per entry
    • Local fallback to localStorage if Firebase not configured

    Security note

    Start with test rules for development, then lock down rules to authenticated users and server-side writes for blockchain/AI actions.
